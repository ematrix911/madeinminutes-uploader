Privacy Policy

MadeInMinutes Uploader · Effective 23 November 2026

MadeInMinutes Uploader ("the tool") is a private, single-user script operated by the owner of the MadeInMinutes YouTube channel. It runs only on the owner's own computer and the owner's own private server, and is not offered to the public. This policy explains how it handles data.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information accessed

With the account owner's authorization through Google OAuth, the tool accesses only the owner's own YouTube channel:

  • Basic channel information and statistics (channel title, subscriber, view and video counts).
  • The list of the channel's own uploaded videos and their public statistics.
  • The channel's own aggregated YouTube Analytics reports (for example views, watch time and audience retention), which contain no information that identifies individual viewers.
  • Permission to upload new videos (and their titles, descriptions, tags and schedule) to that channel.
  • Permission to edit or delete the channel's own videos, used only when the owner asks for a change. This login is separate and is stored only on the owner's computer.

The tool does not access, collect or process data belonging to any other YouTube user.

Meta (Facebook, Instagram, Threads) and Bluesky

The tool also publishes the owner's own short videos to the owner's own accounts on other platforms, through each platform's official API and with the owner's authorization:

  • Facebook and Instagram (Meta app "MadeInMinutes Crosspost"): publishing Reels to the owner's Madeinminutes Facebook Page and the owner's Instagram professional account, and reading those accounts' own aggregated insights (for example views, reach, watch time and follower counts) and like and comment counts.
  • Threads: publishing posts to the owner's own Threads profile and reading their view, like and reply counts.
  • Bluesky: publishing posts with video to the owner's own Bluesky account and reading public like and repost counts.

The tool does not read or store the content of comments or messages, and does not collect personal information about any other user. It does not log in other people, and only the owner's own accounts are connected.

How information is used

Information is used only to upload, schedule, correct or delete the owner's own videos and to let the owner review their channel's performance. It is not used for advertising, profiling, or any other purpose.

Storage

Authorization tokens are stored only on the owner's own computer and the owner's own private server, with access restricted to the owner. Post IDs and links of the owner's own published posts, and periodic aggregate counts (for example views and likes), are kept in local files on those machines. Channel statistics are read on demand and are not stored on any server. No data is kept for longer than needed for these purposes, and no data is stored by the tool for more than 30 days without being refreshed from the API.

Sharing

No information obtained through YouTube API Services is sold, shared with, or disclosed to any third party.

Cookies and tracking

The tool does not use cookies, analytics, or any tracking technology, and does not place information on users' devices.

Revoking access

Access can be revoked at any time from the Google security settings page at https://security.google.com/settings/security/permissions. Locally stored tokens can also be deleted from the computer running the tool.

Data deletion

The tool stores no data about anyone other than the account owner. To delete the data the tool holds:

  • Facebook / Instagram / Threads: remove the app under Facebook Settings → Apps and Websites (or Instagram / Threads → Settings → Website permissions), then delete the stored token files. All tokens stop working as soon as the app is removed.
  • Bluesky: revoke the app password under Bluesky Settings → Privacy and security → App passwords.
  • YouTube: revoke access as described above.

Anyone who believes the tool holds data about them can email the contact address below to request deletion; requests are answered within 30 days.
