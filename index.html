MadeInMinutes Uploader

Powered by YouTube API Services

A private, single-user tool for the MadeInMinutes YouTube channel.

This is not a public application. It is a command-line script that runs only on the channel owner's own computer. There is no website login, no sign-up, and no other users. It is used solely by the owner of the MadeInMinutes channel to manage that channel's own videos.

What it does

  • Uploads the channel owner's own original videos to the MadeInMinutes channel (videos.insert), with title, description and tags.
  • Schedules release times for those videos (status.publishAt).
  • Reads the channel's own statistics and video list (channels.list, playlistItems.list, videos.list) so the owner can review performance.
  • Reads the channel's own aggregated YouTube Analytics reports (views, watch time, audience retention; reports.query) to plan future videos.

Google / YouTube permissions requested

  • youtube.upload: upload videos to the owner's channel
  • youtube.readonly: view the owner's channel and video statistics
  • yt-analytics.readonly: view the owner's own aggregated YouTube Analytics reports

Data

The tool accesses only the channel owner's own YouTube account. Nothing is collected from anyone else, nothing is sent to third parties, and authorization tokens are stored only on the owner's computer. See the Privacy Policy.
